# Hackathon 2: The Evolution of Todo – Mastering Spec-Driven Development & Cloud Native AI

## Hackathon Phases Overview
There are total 5 phases in hackathon 2:

1. **Phase 1:** 
    - `Description:` In-Memory Python Console App
    - `Technology Stack:` Python, Claude Code, Spec-Kit Plus
    - `Points:` 100

2. **Phase 2:**
    - `Description:` Full-Stack Web Application
    - `Technology Stack:` Next.js, FastAPI, SQLModel, Neon DB
    - `Points:` 150

3. **Phase 3:**
    - `Description:` AI-Powered Todo Chatbot
    - `Technology Stack:` OpenAI ChatKit, Agents SDK, Official MCP SDK
    - `Points:` 200

4. **Phase 4:**
    - `Description:` Local Kubernetes Deployment
    - `Technology Stack:` Docker, Minikube, Helm, kubectl-ai, kagent
    - `Points:` 250

5. **Phase 5:**
    - `Description:` Advanced Cloud Deployment
    - `Technology Stack:` Kafka, Dapr, DigitalOcean DOKS
    - `Points:` 300

*Total Points: 1000*
