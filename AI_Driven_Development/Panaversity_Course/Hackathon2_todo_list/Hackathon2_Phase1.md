### Guidelines on Different Practices in Hackathons

- **Why subagents and skills?** So, it simplest answer is one subagent can have multiple skills.
- One of student added voice mode to add tasks and once task added, an email is send to email id provided by student.
- One student make it as project like by giving single command, it will install all dependencies using UV and by typing todo-app, it will run the app on CLI.
- If you used claude and gemini both due to tokens, API limitations, you may face difficulties due to using two CLIs at same time. What you need to do is add Claude.md name in `setting.json` file of .gemini folder. This will reduce your burden b/c you have to manage only one CLI. Gemini automatically manage Claude.
