# Free Claude Code Setup With BonsAI

## 🧠 How to Use Claude Code for FREE using Bonsai CLI

This guide explains step-by-step how to use Claude Code for free using the Bonsai CLI — without any API key or paid subscription.

Bonsai provides access to frontier AI models (including Claude) in stealth mode, where model names are hidden to ensure unbiased evaluation.

## 📋 Prerequisites

Make sure you have the following installed:
* Node.js (v18 or higher recommended)
* npm (comes with Node.js)
* Any terminal (Windows / Linux / macOS)

## Check versions

```bash
node --version
npm --version
```

## 📦 Step 1: Install Bonsai CLI

Install Bonsai CLI globally using npm:

```bash
npm install -g @bonsai-ai/cli
```

## Verify installation

```bash
bonsai --version
```

## 🔐 Step 2: Login to Bonsai

Authenticate your terminal with your Bonsai account:

```bash
bonsai login
```

### What happens?

* A browser window opens
* You log in or sign up
* Your terminal gets authenticated

## ▶️ Step 3: Start Claude Code (FREE)

Start Claude Code using Bonsai:

```bash
bonsai start claude
```

### What this command does:

* Launches a Claude Code session
* Automatically assigns a frontier model
* Runs in stealth mode (model name hidden)
* No API key required

## 🚪 Step 4: Logout (Optional)

Logout from Bonsai anytime:

```bash
bonsai logout
```
